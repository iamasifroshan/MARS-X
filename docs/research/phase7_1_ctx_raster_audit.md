## 2. Critical Area Discrepancy Investigation

### 2.1 The Issue
The Phase 7 report asserted an overlap area of `~3,889.3 km²`. However, computing the area from the raster grid dimensions:
$$3,472 \times 1,692 \times (20.0128\text{ m})^2 \approx 2,352.87\text{ km}^2$$
This presented a significant discrepancy that required mathematical resolution.

### 2.2 Independent Area Calculations
Six distinct area definitions were calculated from the actual geometry and raster data:

1. **Raster Grid Bounding Box Area (Projected Metric Plane):**
   $$\text{Area}_{\text{grid}} = \Delta x \times \Delta y = 33,861.71\text{ m} \times 69,484.56\text{ m} = \mathbf{2,352.87\text{ km}^2}$$
2. **True Geographic Unrotated Bounding Box Area (Spherical Mars):**
   Using Mars spherical radius $R = 3,396,190\text{ m}$:
   $$\text{Area}_{\text{spherical}} = R^2 \times \Delta \lambda_{\text{rad}} \times (\sin\phi_{\max} - \sin\phi_{\min}) = \mathbf{2,410.10\text{ km}^2}$$
3. **STAC Footprint Polygon Area (Oriented Swath Parallelogram):**
   Computing the Shoelace area of the 42-vertex exterior boundary polygon from `stac.json` in Equirectangular projection:
   $$\text{Area}_{\text{swath}} = \mathbf{1,773.50\text{ km}^2}$$
4. **Valid Data Footprint Area (Excluding NoData Border Padding):**
   $$4,281,424\text{ valid pixels} \times (20.0128335\text{ m})^2 = \mathbf{1,714.77\text{ km}^2}$$
   *(The valid data represents $96.69\%$ of the swath polygon and $72.88\%$ of the bounding raster box).*
5. **Actual Overlap Area with MOLA Tile `megt00n000hb`:**
   Since the entire CTX footprint ($[-5.187^\circ, -4.003^\circ] \times [66.036^\circ, 66.617^\circ\text{E}]$) is $100\%$ contained within `megt00n000hb` ($[-44^\circ, 0^\circ] \times [0^\circ, 90^\circ\text{E}]$), the true geographic overlap area is identically **$2,410.10\text{ km}^2$** (spherical bounding box) and **$1,714.77\text{ km}^2$** (valid data area).
6. **Cross-Resolution Sample Grid Footprint Area:**
   The sampling window bounded by $[-5.137^\circ, -4.053^\circ] \times [66.086^\circ, 66.567^\circ\text{E}]$ has a spherical area of **$1,826.03\text{ km}^2$**.

### 2.3 Source of the Discrepancy & Documentation Defect
The value `3,889.3 km²` previously quoted in the text report was an unverified narrative estimate that was never generated by the codebase or the API.
- The actual API endpoint `GET /api/v1/terrain/overlap` and the underlying function `calculate_product_overlap` in `backend/app/terrain/multi_resolution.py` correctly computed and returned **$2,410.1\text{ km}^2$** (the spherical bounding box area).
- The narrative figure `3,889.3 km²` represented an inaccurate documentation claim and has been formally corrected.
- Going forward, all documentation and API descriptions explicitly specify whether they report:
  - **Spherical Bounding Box Overlap:** $2,410.1\text{ km}^2$
  - **Valid Stereo DTM Data Area:** $1,714.8\text{ km}^2$
